# Hub ESCOM-IPN: App Móvil de Convocatorias e Inscripción a Clubes

Plataforma móvil desarrollada en Flutter y Firebase para centralizar las convocatorias, el registro, la carga de comprobantes y la gestión de membresías de los clubes extracurriculares del IPN y ESCOM.

## 🚀 Características Principales
- **Catálogo Centralizado:** Visualización de clubes por categorías (Deportivos, Académicos, Culturales, ESCOM).
- **Inscripción Digital Exprés:** Formulario rápido para postularse a cualquier club.
- **Gestión Documental:** Subida segura de comprobantes de inscripción y pagos directo desde el celular.
- **Estatus en Tiempo Real:** Seguimiento del trámite (Pendiente, Aprobado con QR, Rechazado).
- **Panel de Administración:** Vista para que los líderes de clubes validen documentos y aprueben aspirantes.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** Flutter (Dart)
- **Backend & BaaS:** Firebase (Authentication, Cloud Firestore, Firebase Storage)

## 📱 Requisitos para Ejecutar
- Flutter SDK (versión 3.x o superior)
- Dispositivo físico Android/iOS o Emulador configurado.
